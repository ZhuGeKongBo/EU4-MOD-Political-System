# Political Framework for Europa Universalis IV

**Public Beta 0.1** · Windows x64 · Steam EU4 1.37.5 · Regular single player

Political Framework lets EU4 mod authors define their own political systems, membership rules, offices, resources, succession and panels. The Workshop content includes Ashikaga with daimyo membership and the Mongol Empire with Tumen electors. The source includes two editable examples, Coastal Charter and Harbor Moot.
