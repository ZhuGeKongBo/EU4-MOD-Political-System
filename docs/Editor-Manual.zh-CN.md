# EU4 政治体系编辑器使用手册

**Beta 0.1 · 编辑器 1.0.11 · 框架校验 0.9.2**

编辑器是 Windows 离线工作台。项目文件保存 Mod 内容的工作副本、界面编辑和验证记录。游戏使用导出的 Mod。制作新体系的规则及脚本见 [Modder 教程](Modder-Tutorial.zh-CN.md)，安装见 [安装教程](Install-Guide.zh-CN.md)。

## 第一次打开

1. 解压编辑器 ZIP，运行 `EU4PoliticalEditor.exe`。已有 `.pfproject.json` 时，使用「打开项目…」加载。
2. 想练习时点「打开幕府练习」。想编辑 Beta 或自己的 Mod 时点「打开 Mod…」，选择含 `descriptor.mod` 的解压目录。
3. 在「路径…」中确认游戏本体目录含 `eu4.exe`。玩家目录指向文档中的 EU4 数据，主要供 QA 日志读取。若你的 Mod 继承另一包的体系、布局或素材，把它的解压目录加入依赖。
4. 选择一个具体体系和历史实例，设置预览国家及日期。保存到独立的 `.pfproject.json`。用这份文件继续编辑。
5. 导出前用「预检与导出…」处理错误。将包生成到空的独立输出位置。

依赖列表靠后的同路径文件会覆盖之前的依赖，项目草稿优先。游戏本体提供文件查找的兜底。`replace_path` 会遮住相关依赖和原版路径。让编辑器路径和实际启动器播放集对应，以免预览可见的文件在战役中被覆盖。

## 工具栏

| 项目 | 用途和注意事项 |
| --- | --- |
| 新建 | 建立包含类型和实例的起步项目。给类型、实例和相关文件使用独立 ID。 |
| 从模板 | 选父类型、布局、类型 ID、实例 ID、开局日与领袖。可继承，也可展开复制。复制窗口后仍需核对 GFX 等外部依赖。 |
| 打开 Mod | 读取含 `descriptor.mod` 的目录，建立工作快照。Workshop 的已下载目录可以选作来源。 |
| 打开项目 | 恢复快照与工程设置。移动电脑或目录后，在「路径…」重新指向游戏和依赖。 |
| 保存项目 | 保存 `.pfproject.json`，快捷键 `Ctrl+S`。自动备份用于找回编辑草稿。 |
| 撤销、重做 | 用 `Ctrl+Z`、`Ctrl+Y` 或 `Ctrl+Shift+Z`。一次确认的跨文件修改可一起撤销。 |
| 添加组件 | 打开选择用途、图片和位置的向导。会在确认前列出改动。 |
| 离线试玩 | `F5` 切换编辑与试玩。查看提示、滚动、模拟点击、模拟入口和切实例。实际游戏效果、触发条件及外交结果仍须战役验证。 |
| QA 记录 | 为手动战役验证建立一轮记录，填写用例、结果、退出状态，附截图或导入日志，最后导出证据文件。 |
| 预检与导出 | 检查目录、语法、布局、引用和来源有无变化，生成内容包或增量。 |
| 语言 | 切换简体中文和 English，记住上次使用的选择。影响编辑器文字。 |

## 上方设置与左侧画布

| 项目 | 控制的内容 |
| --- | --- |
| 体系 | 选规则类型。抽象类型用于继承。要看实际面板，选有布局和有效实例的具体类型。 |
| 实例 | 选同一类型的某一份历史或实例。影响领袖、成员、职位和资源。 |
| 国家、历史日 | 模拟由哪个国家在该日期查看。用于观察开局历史与筛选结果。 |
| 游戏文本 | 选择预览使用的本地化语言，与程序本身的「语言」分开。 |
| 路径、语法参考 | 路径管理文件来源，语法参考提供字段和样例。实际支持以框架 API 清单及预检为准。 |
| 分辨率、UI 比例、画布 | 模拟分辨率与 UI 比例，用画布缩放来方便编辑。写入的是原生局部坐标。 |
| 命中详情 | 核对所选控件的范围、实际鼠标命中与信息，用来诊断叠放和无提示。 |
| 控件列表、X/Y、应用坐标 | 选中被覆盖的部件时可用下拉框，输入精确位置后应用。也可以在画布直接拖动。 |
| 编辑共享布局 | 明确启用后一起修改引用该布局的类型，确认框列出影响范围。仅为当前类型改动时使用默认设置。 |
| 改手动 | 将自动排列的盾徽当前位置写回 GUI，用于逐个编辑。自动模式请移动整个框。 |
| 已发现、入口状态 | 离线模拟已发现首都与入口隐藏、置灰、可用。真实可见性由战役和脚本决定。 |
| 排布选举区、评分贴右下 | 前者整体调整选举区，后者只把评分与自己的悬停区贴到盾徽右下。 |
| 整组移动席位 | 勾选后拖大盾徽会带动该席的文字、评分、悬停区和小盾徽。默认单独移动。 |
| 删除组件、绑定与修复 | 移除独立组件，或先改绑正在使用的控件。必需控件可更换或恢复。 |

手动职位区允许控件叠放和跨排。绿线标出所选部件在面板内的可放范围。要检查下层控件，使用控件列表选中它，再检查命中详情和试玩的实际鼠标位置。

## 右侧文件与代码

| 页签 | 这里编辑什么 |
| --- | --- |
| 类型 | 继承字段、领袖、成员来源、职位、资源、行动和入口规则。 |
| 布局 | 类型用哪个 GUI 窗口，各位置、编号和原生控件担当哪种用途。 |
| GUI | 控件、坐标、尺寸、叠放顺序、按钮和悬停区域。 |
| GFX | sprite 名、纹理相对路径和帧数。 |
| 历史 | 实例与类型、建立日、领袖、成员、职位和后续日期变更。 |
| 本地化 | 标题和玩家提示。使用当前游戏语言的文件后缀与文件头，保存 UTF-8 BOM。 |

顶部下拉框切换当前文件。「来源」指出实际读取位置。「差异」比对原文与草稿。「查找替换」在当前文件内操作，`Ctrl+F` 查找，`Ctrl+H` 替换。遇到草稿语法错误时，画布可能保留上一份可解析视图。先修右侧出错行，再把画布当成当前内容判断。

## 添加组件的向导

1. 在「选择作用」里选用途。添加提示徽记可选「图标＋悬停提示」并直接填写说明。给改革换按钮时选「连接已有行动」，再选已有的改革或诏令。面板入口需要选择「入口按钮」。
2. 在「选择图片」中可复用素材库里的 sprite，或导入自己有权使用的 DDS/TGA。「手动填写素材参数」用于自行选 sprite ID、GFX 登记文件、项目相对纹理路径与帧数。尽量从现有素材入手核对效果。
3. 在「放到面板」中选父窗口，点击画布位置或填写 X/Y，预览并确认改动。入口位置由 HUD 的容器分配，普通装饰图标使用其父窗口局部坐标。

装饰图标只负责绘制。提示图标额外生成只读命中区。「连接已有行动」复用脚本的机制和权限。替换材质只变外观。文本、只读提示区、资源余额和资源月变分别通过对应绑定进行显示。已占用的绑定需要你确认替换。

## 副本、导出与冲突

- **完整内容包**包含项目合并后可见的 Mod 文件与所需描述文件。先检查清单中的依赖、替换范围和素材授权。发布时选你希望交付的自己的内容。
- **增量包**只写工程新增或改动的文件，供在已知基线上更新。核对目标版本和差异。
- 「源差异…」检查导入快照后外部文件是否变化。若另一编辑器修改了源文件，用新快照合并或明确选择旧快照。导出到新目录可防止误覆盖。
- QA 的「开始一轮」记录基线。之后自行进游戏，回来读取本轮日志、填结果，必要时标为未测或失败。离线试玩用于在进游戏前核对界面。

| 如果遇到 | 处理方式 |
| --- | --- |
| 两个类型或同名窗口冲突 | 查看「来源」及依赖顺序。给独立体系、历史实例、窗口和 sprite 独立命名。一次启用同一内容的一个版本。 |
| 相同文件被另一个 Mod 覆盖 | 对照实际播放集。留意 `replace_path`、同路径 GFX/GUI 和重复 `interface` 字段。 |
| 绑定缺失、删除失败 | 打开「绑定与修复…」，改绑仍被其它对象引用的组件，或先移除可选显示。数字同时检查只读区域。 |
| 画布和成品位置不同 | 分清自动框、手动坐标与 UI 缩放。确认已导出这次修改，进游戏加载配套的 0.9.2 框架与内容。 |
| 本地化原样显示键名 | 查 UTF-8 BOM、语言头、文件后缀、键名大小写和加载顺序。检查动态参数声明路径。 |
| 点入口后闪退 | 先看第一个预检错误。GUI 的 `tooltip` 应指向原生样式，悬停文案键放进 `tooltipText`。再检查 `anvil/anvil.log` 与崩溃报告。 |
| 文档目录或资源打不开 | 检查实际 Steam 库与玩家目录，手动补路径。导入先解压到可读写目录。 |
| 导出仍有原有错误 | 独立改动可先保存，导出前逐项处理错误。定位到真实冲突文件与控件。 |

## 快捷键

`Ctrl+S` 保存工程，`Ctrl+Z` 撤销，`Ctrl+Y` 重做，`Ctrl+F` 查找，`Ctrl+H` 替换，`F5` 切换离线试玩，画布或控件列表获得焦点且可删除时按 `Delete` 打开删除流程。
