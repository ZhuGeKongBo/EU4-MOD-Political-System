# Editable examples

| Example | Contents | Dependency |
| --- | --- | --- |
| `DefaultType/Default-Fields.zh-CN.txt` | Annotated default and message fields. Stored outside the game's loaded type folder. | None to read |
| `ReuseTemplate/coastal_charter` | A Celestial-style type, dated history, a native effect and a localised bulletin. | Install runtime 0.9.2 and enable the Beta content |
| `FromScratch/harbor_moot` | Independent type, history, GUI, GFX and HUD region. | Runtime 0.9.2 |

Each playable example has a folder and an adjacent `.mod` file. Copy the two together for local testing. The examples can be edited as text or opened in the editor. See [release validation](../docs/Validation.md) for the tested scope.
