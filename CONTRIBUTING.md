# Contributing

Political Framework Beta 0.1 is an invitation to build and share new political systems for EU4. Contributions to examples, documentation, editor UX and the framework are welcome.

1. Start with a small sample. Include its type, history and bindings for changes to content. Reproduce layout issues with the relevant window and HUD files.
2. For code changes, use a topic branch and submit a pull request. Describe the expected behaviour, test it, and state which results were offline and which were in a real campaign.
3. Keep UI and validation data-driven. Verify a change on a new type with different dimensions and control names. A new system using existing mechanics should work with the same binary.
4. Include EU4, Anvil, framework and editor versions in an issue. Share only the necessary excerpt of a log or crash report. Redact usernames, personal paths and account identifiers.
5. Submit material you own or can contribute under the applicable terms. Contributions to the MIT-licensed code are intended for distribution under the project's MIT license. Preserve third-party notices and reference base-game assets by ID.

See [Building](BUILD.md), the [content examples](examples/README.md), and [Notices](NOTICE.md).
